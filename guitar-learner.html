Install This App

Turn Jason’s Guitar Basics into a full-screen app on your phone or computer.

  • Phone (Android – Chrome): Open this page → tap the menu (⋮) → “Install app” or “Add to Home screen”. You can also use the Install App button in the top bar when it appears.
  • iPhone (Safari): Open this page → tap the Share button → “Add to Home Screen” → Add. It will open full-screen like a normal app.
  • Computer (Chrome / Edge): Look for the install icon in the address bar, or click the Install App button when it shows up.
  • Best experience: Host the files on a free https site (Netlify Drop, GitHub Pages, etc.) so the microphone and install features work reliably. Opening the local file still works for most features.
  • Keep these files together: guitar-learner.html, manifest.json, sw.js, and the icon files.

Beginner Tips (Left-Handed Friendly)

  • Lefty Mode: Turn on the toggle in the top right. All chord diagrams mirror so the low E string is on the right (how you see the neck).
  • Thumb: Keep it behind the neck for open chords — more room for your fingers to arch.
  • Close to the frets: Press just behind the metal fret. Cleaner sound, less effort.
  • Arch fingers: Use fingertips so you don’t mute neighboring strings.
  • Start small: Master Em → Am → G → C → D first.
  • Slow = fast: Perfect changes at slow tempo. Speed comes automatically.
  • Strumming: Loose wrist. Downstrokes on the beat numbers, upstrokes on the “+”.
  • Short daily sessions: 15–20 focused minutes beats one long frustrated hour.
  • Calluses: Fingertips will hurt at first. They toughen in 1–3 weeks.
  • Tune every time: Use a clip-on tuner or phone app.

Beginner Rock Starter Set

Follow this order — each song builds on the chords from the previous ones.

  1. Em + D → Horse with No Name (easiest possible song)
  2. A + D + E → Wild Thing (classic 3-chord garage rock)
  3. D + C + G → Sweet Home Alabama + Bad Moon Rising
  4. G + C + D + Em → Good Riddance (Time of Your Life) + Brown Eyed Girl
  5. Em + C + G + D → Zombie (great 90s alternative feel)
  6. Em + G → About a Girl (Nirvana – simple grunge)
  7. G + D + Am + C → Knockin’ on Heaven’s Door (Dylan / GNR)

Chord Learning Order

  1. Em & Am (only two fingers each)
  2. G & C
  3. D
  4. E & A
  5. Dm (slightly harder stretch)
